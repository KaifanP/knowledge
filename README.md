# COMP30023 Interactive Revision

Interactive revision website generated from the COMP30023 weekly Markdown notes.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The app reads the `WK*.md` files and the `images/` folder directly. `npm run dev` and `npm run build` copy `images/` into `public/images` before starting Vite.
